Step 1

站点信息

生成 public/data/site.config.json

这里用来改首页文字、头像、左侧身份栏、颜色。

填写完成后点击下面的“下载 site.config.json”，然后把下载到电脑里的文件上传覆盖 GitHub 仓库里的 public/data/site.config.json。

头像上传会被写进配置文件，适合小图片；如果图片很大，建议先压缩再上传。

Step 2

作品集

生成 public/data/site.config.json

这里用来新增、删除作品集，也可以给作品集设置封面。

作品集 ID 是给代码识别用的，建议用英文、小写字母和短横线，例如 lu-yuan。作品集标题才是读者看到的名字。

修改后同样下载 site.config.json，上传覆盖 GitHub 的 public/data/site.config.json。

Step 3

新增文章

生成文章 HTML + public/data/posts.json

这里有两种发布方式。

方式 A：直接在编辑框里写文章，使用上方格式按钮排版，右侧预览满意后，依次下载“文章 HTML”和“posts.json”。文章 HTML 上传到 public/posts，posts.json 上传覆盖 public/data/posts.json。

方式 B：你已经有完整 HTML 文件，就先把那个 HTML 上传到 GitHub 的 public/posts，再在“已有 HTML 文件名”里填写文件名，例如 lu-yuan-shuangfeng.html，最后只下载并上传 posts.json。

标签用英文逗号分开，例如 论坛体, 短篇。作品集内顺序数字越小，越靠前。

预览

导出

上传位置：

文章 HTML：public/posts

文章目录：public/data/posts.json

上传到 GitHub 后，Vercel 会自动更新。

Step 4

管理文章

生成 public/data/posts.json

这里可以调整文章顺序、删除文章，或者把文章设为仅自己可见。

“仅自己可见”不会删除文章文件，只是让首页不展示它。真正删除文章时，建议同时去 GitHub 的 public/posts 里删除对应 HTML 文件。

改完后点击“下载 posts.json”，上传覆盖 GitHub 的 public/data/posts.json。

Step 5

管理标签

生成 public/data/posts.json

这里会批量改所有文章里的标签。

例如把 论坛体 改成 论坛体文章，所有使用这个标签的文章都会一起更新。

改完后点击“下载 posts.json”，上传覆盖 GitHub 的 public/data/posts.json。

Supabase

评论管理

Supabase Table Editor

评论不保存在 GitHub 文件里，而是保存在 Supabase 数据库里。

查看评论：打开 Supabase 项目，左侧点击 Table Editor，进入 comments 表。

删除评论：在 comments 表中找到那条评论，点这一行最左边的选择框，再点页面上的删除按钮。

识别回复：普通评论的 parent_id 是空的；回复评论的 parent_id 会指向它回复的那条评论。

查看点赞：文章喜欢在 likes 表；评论喜欢在 comment_likes 表。

如果评论发不出去，先检查 Vercel 的 Environment Variables 是否有 SUPABASE_URL 和 SUPABASE_SERVICE_ROLE_KEY 或 SUPABASE_PUBLISHABLE_KEY，再确认 Supabase 运行过 supabase/comments.sql。
